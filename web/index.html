    About / Known Limitations
    
    
      
  • Stack ops (push, pop, call, ret) and interrupts are not yet implemented — programs using them will crash and show an error.
    • 
      
  • Flag branches (BrFlagIm/Rg) are not implemented.
    • 
      
  • The cycle limit defaults to 50,000,000. The Primes example is slow — use maximum speed and wait a moment.
    • 
      
  • MMIO input (keyboard → CPU) is not implemented; output only.
    • 
      
  • r0 is the zero register and always reads 0.
    •
